# SpendWise – Smart Budget and Expense Tracker

## 1. Project Description
SpendWise is a web-based budget and expense tracking application designed to help students, young professionals, and small business owners manage their finances.

The application helps users monitor their budgets, record expenses, and understand their remaining balances.

## 2. Project Features
- Budget tracking and expense monitoring.
- Display of total budget, total expenses, and remaining balance.
- Expense categorization, including Food, Transport, Rent, Entertainment, Savings, and Utilities.
- Add and delete expense records.
- Display expense details in a table.
- Responsive user interface.
- Organized layout using HTML, CSS, and JavaScript.

## 3. Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Application functionality.
- Git and GitHub – Version control and source code hosting.
- Netlify – Website hosting and deployment.

## 7. Deployment Process
1. Created a public GitHub repository named SpendWise.
2. Initialized Git in the local project directory.
3. Added and committed the project files.
4. Pushed the source code to GitHub.
5. Connected the GitHub repository to Netlify.
6. Configured the deployment settings.
7. Published the website using Netlify.
8. Customized the Netlify subdomain.
9. Made a visible change to the website.
10. Committed and pushed the changes to GitHub.
11. Verified the automatic deployment on Netlify.
